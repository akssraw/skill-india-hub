# AI Usage Documentation

## Tools Used

- **Claude (Anthropic)**
  - **Purpose:** Content generation, structure planning, and code optimization
  - **Use Cases:** Generated the initial layouts for `/about` and `/explore` pages. Optimized Tailwind classes for responsive design.
  - **Sample Prompts:** 
    - "Generate a responsive React functional component for an about page showcasing a mission statement and team."
    - "How can I optimize this React component's rendering performance?"
  - **Human Review Process:** All generated content and code were reviewed, manually refactored, and tested to ensure it fits the project's architecture and design system.

- **ChatGPT (OpenAI)**
  - **Purpose:** Debugging, configuration, and writing utility functions
  - **Use Cases:** Debugging Vite configuration, writing form validation logic.
  - **Sample Prompts:**
    - "Write a regex pattern to validate a standard email address format in JavaScript."
    - "Why is my Vite build failing with this specific PostCSS error?"
  - **Human Review Process:** Code snippets were tested in isolation before integration.

- **Midjourney**
  - **Purpose:** Image generation for placeholder assets
  - **Use Cases:** Generated `hero.png` used on the landing page.
  - **Sample Prompts:**
    - "A modern, abstract digital illustration representing skill development and education, clean background, blue and purple tones, UI asset --ar 16:9"
  - **Human Review Process:** Images were scaled and optimized using standard tools before adding them to the repository.
